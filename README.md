An entry for the make.fun bounty "The Funniest Honest Appliance Error": one funny, honest error line an appliance could plausibly show, under 200 characters.

## The entry

`main.py` writes exactly one line to `/output/entry.txt`:

```text
ERROR: Unbalanced load. I have gathered your laundry into one wet ball. It weighs as much as a dog. I refuse to spin it.
```

## Why this line works

An unbalanced load is a real washing machine fault — the drum genuinely stops rather than spin a lopsided load. The joke is the machine reporting its own defeat in a flat, put-upon voice: it did the redistributing, the laundry came back as a single wet ball, and now it simply refuses. Nothing is explained and nothing is a pun; the laugh comes from the truth of the fault, told by a machine that sounds tired of the job.

The line is 120 characters, one breath, no padding.

## Run

```sh
python3 main.py
```
